# raster-digital-divide

Análisis geoespacial de la brecha digital territorial en la región Cusco (Perú) cruzando luces nocturnas (NASA VNL 2025) y cobertura móvil (OSIPTEL 2019).

## Setup

```bash
pip install -r requirements.txt
```

Los rasters de entrada van en `data/` (no se trackean, descarga desde el Drive del curso).

## Correr el notebook

```bash
jupyter notebook notebooks/digital_divide_cusco.ipynb
```

Los outputs aparecen en `output/`.
